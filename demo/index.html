Local ATS Resume Matcher — try it in your browser

Free, local, privacy-first resume scorer. Paste a job description and your CV, click Score my resume, and get a match score out of 100, matched vs missing keywords, and plain-language fixes. Nothing is uploaded — the scoring runs entirely in this page, on your machine. No account, no API key, no server.

Already filled in with the sample files, so it works in one click: a fictional Junior Data Analyst CV vs a real anonymised NHS Jobs posting for a Junior/Intermediate Data Analyst (27 November 2025; source: sample_data/job.SOURCE.md). Replace either box with your own text and re-score.

How scoring works

AreaPointsWhat it measures
Keyword coverage50Share of job-description keywords found in the CV
Skills match20Share of hard + soft skills named in the job that appear in the CV
Experience & education15Degree (5), years of experience (5), quantified achievements (5)
Formatting15Email (4), phone (3), LinkedIn/URL (2), 3+ sections (4), 1–2 pages (2)
Total100

Matching is whole-phrase and case-insensitive, so “java” never matches “javascript”, and a skill is never counted twice. The sample CV scores 36/100 — keyword coverage 2.5/50, skills 1/5 (4.0/20), experience & education 15.0/15, formatting 15.0/15. The low keyword score is honest: a retail analyst’s CV genuinely does not use healthcare data language. The tool discriminates instead of flattering every resume — apply the fixes and re-run to see it move.

This page is a JavaScript port of the Python tool in this repo (ats_match/scorer.py + ats_match/keywords.py). The Python tool extracts job keywords with spaCy’s noun phrases when the model is installed; browsers can’t run spaCy, so this page uses a rule-based noun-phrase chunker that reproduces the Python score exactly on the bundled sample (36/100) and on a second test CV (79/100). The underlying keyword sets can differ by a phrase or two on other job descriptions — the scoring maths (weights, regexes, fix text) is identical. To run the Python original, see the README. A static sample report is at the project homepage.
