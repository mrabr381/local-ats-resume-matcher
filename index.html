Try it yourself

git clone https://github.com/mrabr381/local-ats-resume-matcher.git
cd local-ats-resume-matcher
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m spacy download en_core_web_sm
python -m ats_match --resume sample_data/resume.pdf --job sample_data/job.txt --out report/

Or run the web app: streamlit run app.py
